AI Prompt — Website Redesign (White Theme)

Redesign the existing "Vu Phan, Realtor®" one-page real estate website with a clean white background aesthetic.

Design Requirements:
- Primary background: Pure white (#FFFFFF)
- Alternating section backgrounds: Off-white (#FAFAF8) and Cream (#F5F3EE)
- Accent: Warm gold (#B8933F) for headings, icons, and call-to-action highlights
- Text: Deep charcoal/ink (#111110) for headings, muted slate (#6B6860) for body
- Dark sections: Reserved ONLY for Hero overlay, Valuation section, and Footer
- Typography: Cormorant Garamond (serif, italic headings) + Inter (clean sans body)
- Navbar: Fully transparent over hero image, transitions to white with blur backdrop on scroll
- All cards: White background with 1px border and subtle 2-pixel shadow — no heavy drop shadows
- Scroll animations: IntersectionObserver fade-up reveal on all major sections
- Mobile: Full-screen frosted-glass hamburger nav overlay
- Hero: Keep Philadelphia skyline image, reduce overlay opacity for lighter feel

Maintain all existing functionality:
- Neighborhood grid, filtered listings, valuation form, contact form
- Google Business & Maps integration
- All Vu Phan contact details unchanged

How to Manage the Site

  • Update listings: Edit the SITE_DATA.listings array in script.js — change prices, addresses, tags, or add new property objects.
  • Update phone / address: Edit the top of SITE_DATA in script.js — all contact details cascade automatically.
  • Change colors: Edit CSS custom properties (variables) at the top of style.css under :root {}.
  • Deploy: Upload the entire claude/ folder contents to GitHub Pages, Vercel, Netlify, or any web host.
